# XXL Ritter – Asset Folder

Place the following image files here so they are served at runtime:

- `Ritter_XXL_Logo_grau.png`     → navigation logo
- `XXL-Ritter_Herzogenweiler_Restaurant.jpg` → hero + gallery
- `XXL-Ritter_Herzogenweiler_hoel.jpg`       → hotel section + gallery
- `Außen.jpg`                                → hero background + gallery

These files are referenced in the app via `/assets/<filename>`.
